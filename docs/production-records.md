# 이미지 제작 기록

이미지 카드의 `제작 기록` 패널과 사용량 통계는 생성 파이프라인이 남긴 구조화된
영수증을 사용한다. 파일명이나 프롬프트 문자열에서 등장인물과 화풍을 추측하지 않는다.

## 기록 형식

```json
{
  "schemaVersion": 1,
  "imageId": "image-20260729-001",
  "jobId": "job-20260729-001",
  "characters": ["헤일라", "리벨라"],
  "relationGroup": "성녀 pair",
  "style": "고딕",
  "createdAt": "2026-07-28T17:17:00.000Z",
  "durationMs": 154000,
  "retryCount": 0
}
```

`createdAt`은 UTC ISO 시각으로 저장하고 화면에서 서울 시간으로 표시한다.
`durationMs`는 밀리초, `retryCount`는 최초 시도를 제외한 재시도 횟수다.

## 보안 경계

- `imageId`와 `jobId`는 경로가 아닌 안전한 불투명 식별자다.
- 절대경로, 프롬프트 원문, 키, 계정 정보와 외부 API 원문은 기록하지 않는다.
- 알 수 없는 필드가 들어오면 조용히 보관하지 않고 검증 오류로 거부한다.
- 즐겨찾기와 사용자 메모는 생성 영수증을 변경하지 않고 별도 상태로 관리한다.

## 다음 연결

Image Studio 이전 시 생성 작업이 완료되는 지점에서 이 영수증을 한 번 기록한다.
이미지 상세 API는 영수증의 허용된 필드만 반환하고, 카드 패널은 그 응답을 표시한다.
