# 하나빛 모바일 Web Push

## 연결 방법

Owner Only 허브의 `/notifications`를 모바일에서 연 뒤 `알림 켜기`를 누른다.
브라우저 권한 창에서 허용하면 해당 기기의 Push 구독이 Git 제외 상태 폴더에
암호화 키와 함께 저장된다. VAPID 개인키와 구독 endpoint는 API로 반환하거나
로그에 출력하지 않는다.

- Android Chrome: HTTPS 운영 주소에서 바로 구독할 수 있다.
- iPhone/iPad: Safari에서 허브를 홈 화면에 추가하고, 추가된 웹 앱에서 알림을 켠다.
- `그냥 보고팠어요!!!!!` 버튼은 현재 연결된 모든 하나빛 모바일 구독으로 테스트
  알림 한 건을 전송한다.

## 알림 계약

| 종류 | 문구 | 현재 자동 연결 |
| --- | --- | --- |
| `image.completed` | 이미지 생성이 완료되었어요오!!! | 연결 예정 |
| `news.created` | 뉴스가 올라갔어요오!!!! | 연결됨 |
| `news.duplicate-review` | 뉴스가 중복이에요!!!! 사람 판단이 필요해요오오오!!!!! | 스토리 중복 판정 후 연결 예정 |
| `theme.registered` | 오늘의 테마가 정상 등록되었어요오!!!! | 연결 예정 |
| `fortune.registered` | 오늘의 운세가 정상 등록되었어요오!!!!!!! | 연결 예정 |
| `test.missed-you` | 그냥 보고팠어요!!!!! | 수동 테스트 연결됨 |

뉴스 감시기는 번역과 판정이 끝난 `pending_review` 항목만 알린다. 실제 Push 전송이
한 기기 이상 성공하면 뉴스 항목에 안전한 발송 영수증을 남겨 재접속과 10분 보충
확인에서 같은 알림을 반복하지 않는다. Push 구독이 없으면 영수증을 남기지 않는다.

이미지·테마·운세 자동 알림은 기존 외부 파이프라인과 Windows 예약 작업을 변경하지
않은 채 각 완료 영수증 경계가 확인된 뒤 별도 단계로 연결한다.
